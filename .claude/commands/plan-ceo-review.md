# Plan CEO Review

从 CEO（最终决策者）视角审视计划。关注战略价值而非执行细节。

## 使用方法

`/plan-ceo-review` - 审查当前 PLAN.md
`/plan-ceo-review [计划内容]` - 审查指定计划

## 审查流程

### Step 1: 战略价值评估

首先问：做这件事的战略价值是什么？

**评估维度：**
- 这个计划如何服务于公司愿景？
- 是否与当前优先级一致？
- 机会成本是什么？

### Step 2: 结果导向审查

**关键问题：**
1. **成功标准是什么？**
   - 如何衡量成功？
   - 是否有可量化的指标？

2. **价值交付时间线？**
   - 多久能看到价值？
   - 是否符合业务时间线？

3. **风险调整后的回报？**
   - 最好的情况回报多少？
   - 最坏的情况损失多少？
   - 概率加权后的期望值？

### Step 3: 资源评估

**评估资源投入：**
- 开发资源（人/时间）
- 基础设施成本
- 维护成本
- 机会成本

**决策框架：**
| 情况 | 决策 |
|------|------|
| 高价值 + 低成本 | 立即执行 |
| 高价值 + 高成本 | 寻找降低成本方案 |
| 低价值 + 任何成本 | 重新考虑或放弃 |

### Step 4: 优先级确认

**决策矩阵：**

```
                低风险        高风险
            ┌─────────────┬─────────────┐
        高  │   立即做    │   重点做    │
      价 值  │             │             │
            ├─────────────┼─────────────┤
        低  │   快速做    │   重新考虑  │
      价 值  │             │             │
            └─────────────┴─────────────┘
```

## CEO 问题清单

### 战略问题
- [ ] 这个计划与公司战略有什么关系？
- [ ] 如果成功，3年后会有什么不同？
- [ ] 不做的后果是什么？

### 执行问题
- [ ] 团队是否有能力执行？
- [ ] 时间线是否现实？
- [ ] 有什么关键依赖？

### 风险问题
- [ ] 主要风险是什么？
- [ ] 我们能承受多大风险？
- [ ] 最坏情况是什么？

### 资源问题
- [ ] 需要多少资源？
- [ ] 资源优先级是否正确？
- [ ] 机会成本是什么？

## 输出格式

```
🏢 CEO 审查报告

📊 战略评级: A/B/C/D

💡 战略价值:
- [评估]

⚠️ 主要风险:
- [风险1] - 概率/影响

💰 资源需求:
- 估计成本
- 机会成本

✅ 建议:
- 立即执行 / 重新设计 / 暂缓 / 放弃

📋 关键问题需要回答:
- [问题1]
- [问题2]
```

## 决策准则

1. **NOISE 原则**: 如果不这样做，噪音会更大吗？
2. **首日原则**: 如果这是你创业第一天，你会做吗？
3. **删除测试**: 如果没有这个功能，最小可行产品还能工作吗？
