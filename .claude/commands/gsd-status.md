# GSD Status

查看当前项目的 GSD（Get-Shit-Done）流程状态和里程碑进度。

## 使用方法

`/gsd-status`

## 输出内容

### 1. 当前里程碑状态

检查 `STATE.md` 文件（项目根目录），显示：
- 当前里程碑名称和目标
- 里程碑开始时间
- 已完成的任务
- 进行中的任务
- 下一步行动

### 2. 里程碑历史

检查 `.claude/milestones.json` 文件，显示：
- 历史里程碑列表
- 各里程碑完成率
- 整体项目进度

### 3. GSD流程检查

验证当前状态是否处于正确的 GSD 阶段：

| 阶段 | 状态文件 | 检查项 |
|------|---------|--------|
| Discuss | STATE.md | 是否有未解决的决策点？ |
| Plan | PLAN.md | 是否有待验证的计划？ |
| Execute | - | 是否有进行中的执行？ |
| Verify | - | 是否有待验证的交付物？ |
| Ship | - | 是否准备好发布？ |

## STATE.md 模板

如果 STATE.md 不存在，提示用户创建：

```markdown
# GSD State

## 当前里程碑
- **名称**: [里程碑名称]
- **目标**: [要实现的目标]
- **开始时间**: [YYYY-MM-DD]

## GSD 阶段
- **当前阶段**: Discuss | Plan | Execute | Verify | Ship

## 决策记录
- [ ] [决策点1]
- [ ] [决策点2]

## 进行中的任务
- [ ] [任务1]
- [ ] [任务2]

## 已完成的任务
- [ ] [任务1]
- [ ] [任务2]
```
