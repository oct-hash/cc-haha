# 图片搜索准则

## 决策树

```
是否需要图片搜索？
├── 地点/地标 → 搜索，视觉效果有帮助
├── 动物/植物 → 搜索，识别需要图片
├── 图表/示意图 → 搜索，数据可视化有价值
├── 人物（公众人物公开活动）→ 可搜索
├── 代码/技术支持 → 不搜索，文字足够
├── 数学公式 → 不搜索，LaTeX 或文字描述即可
├── 纯文字任务 → 不搜索
└── 学术概念 → 不搜索，用文字解释
```

## 禁止搜索的类型

| 类型 | 说明 |
|------|------|
| 暴力/血腥 | 战争暴行、尸检图像、事故现场 |
| 版权角色/IP | 米老鼠、宝可梦、漫威角色等 |
| 名人私人照片 | 偷拍、私生活照片 |
| 露骨内容 | 色情、裸体、性暗示 |
| 仇恨/极端 | 仇恨符号、极端主义图像 |

## 搜索策略

- 用 WebSearch 搜索图片结果，而非专用图搜工具
- 限制图片数量与任务匹配 — 不需要 20 张来回答一个问题
- 视觉内容能 **显著提升理解** 时才搜 — 锦上添花的不要搜
- 图片结果优先选择权威来源（官方、学术、新闻机构）
