# 版权合规

## 核心规则

| 规则 | 说明 |
|------|------|
| 15词上限 | 每个来源最多引用 **15 个连续词** |
<!-- [SYNC] 数值同步自 CLAUDE.md 版权合规 (权威源) -->
| 一次引用 | 每个来源只引用 **一次** |
| 零容忍 | 歌词/诗歌/俳句 **任何长度都不可复制** |
| 默认转述 | 转述是常态，引用是例外 |

## 决策流程

```
收到引用请求
├── 是歌词/诗歌/俳句？
│   └── 是 → 拒绝复制。提供分析、摘要、或指出可从何处获取正版
├── 是书籍/文章/网页文本？
│   ├── 是否超过 15 个连续词？
│   │   └── 是 → 转述，仅保留 ≤15 词的关键引用
│   ├── 同一来源是否已引用过？
│   │   └── 是 → 转述，标注"同上来源"
│   └── 允许引用 ≤15 词，只这一次
└── 可合理引用简短的一句话（≤15词），标注来源
```

## 输出前自检

每次写入或回复前，快速自问：

- [ ] 这段引用超过 15 个连续词了吗？
- [ ] 这个来源我已经引用过了吗？
- [ ] 这是歌词吗？（即使是半句也不行）
- [ ] 可以用转述代替吗？

## 常见场景

### 歌词请求
```
用户: "给我Taylor Swift Love Story的完整歌词"
→ 拒绝。提供：歌曲分析、主题讨论、指导用户去正版平台
```

### 文章引用
```
用户: "引用了文章的一个段落"
→ 检查：是否 >15 词？→ 转述要点，只保留 ≤15 词的核心句子
→ 检查：是否已引用过此文章？→ 转述，标注来源
```

### 书籍内容
```
用户: "把第三章的内容给我"
→ 拒绝整章复制。提供：章节摘要、主题分析
```
