# Marketplace 技能

用于浏览和搜索 Claude Code 技能市场。

## 使用方法

### /skill marketplace

列出所有可用的技能。

### /skill marketplace search <关键词>

按名称、描述、标签或作者搜索技能。

### /skill marketplace browse

浏览所有市场技能。

## 当前市场技能

当前可用的本地技能：
- **git-master**: 分析 commit 意图，提供 code review 建议，检测冲突根因
- **ai-scientist**: AI-Scientist-v2 多智能体学术论文写作系统
- **paper-tree**: PaperTree 多智能体论文分析系统

## 功能

- 浏览所有可用技能
- 按名称/标签/作者搜索
- 查看技能详情（版本、作者、标签）
