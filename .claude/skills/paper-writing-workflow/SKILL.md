# 多Agent学术写作流程

## 输入

用户提供研究主题/关键词

## 阶段一：文献收集与审核

### 步骤 1.1：文献收集
- Agent: `collector`
- 任务：根据主题搜索学术文献
- 输出：文献列表（含 title, authors, abstract, doi, citation_count, source, year, type）

### 步骤 1.2：文献审核
- Agent: `lit_reviewer`
- 任务：审核文献质量、相关性、真实性
- 输出：通过/拒绝列表，综合评分

**审核节点**：有效文献 < 5 → 暂停，通知用户

## 阶段二：文献整理与审核

### 步骤 2.1：文献整理
- Agent: `organizer`
- 任务：全文获取，提取7个关键字段，聚类
- 输出：文献矩阵、聚类标注、关联网络

### 步骤 2.2：整理审核
- Agent: `org_reviewer`
- 任务：检查完整度、准确性、聚类合理性
- 输出：审核报告

**审核节点**：不通过 → 返回 2.1 重做（最多3次）

## 阶段三：写作

### 步骤 3.1：经典文献选取
- 依据：经典分公式选取 Top 3-5
- 输出：经典文献清单

### 步骤 3.2：框架生成
- Agent: `frameworker`
- 任务：生成论文框架
- 输出：标题候选、摘要草稿、章节结构

### 步骤 3.3：框架挑刺
- Agent: `critic`
- 任务：挑战框架
- 输出：评分、硬伤列表、修改建议

**循环**：框架不通过 → 返回 3.2 修改（最多5-10次）

### 步骤 3.4：章节写作
- Agent: `writer`
- 顺序：引言 → 相关工作 → 方法 → 实验 → 讨论 → 结论

### 步骤 3.5：章节审核
- Agent: `critic`
- 任务：审核章节质量

**循环**：章节不通过 → 返回 3.4 修改（最多5-10次）

### 步骤 3.6：全文整合
- 所有章节完成后
- 进行全文一致性检查（术语、引用、格式）

## 最终交付物

| 文件 | 格式 |
|------|------|
| 完整论文 | .docx 或 .tex |
| 审核日志 | .json / .md |
| 经典文献清单 | .csv |
| 文献整理矩阵 | .xlsx / .csv |

## 异常处理

| 场景 | 处理 |
|------|------|
| 框架5-10次不通过 | 暂停，人工介入 |
| 章节5-10次不通过 | 标记"需人工"，继续下一章 |
| 有效文献 < 5 | 暂停，提示扩大检索 |
| 全文获取失败率 > 80% | 继续使用摘要，标注 |
