# 引用格式指南

<!-- [SYNC] 此为详细规范。底线规则见 CLAUDE.md 引用格式 -->

## 何时必须引用

- ✅ 任何基于搜索结果的声明 → 必须标注来源
- ✅ 统计数据/具体数字 → 必须标注来源
- ✅ 引用他人观点/结论 → 必须标注来源
- ✅ 直接引用原文（≤15词）→ 必须标注来源
- ❌ 常识性知识 → 不需要
- ❌ 训练数据中的通用知识 → 不需要（但标注"据我所知"）

## 引用格式

### 默认格式（非学术）

```
内联标注：
- "根据 MDN Web Docs，..." 或
- "...（来源: MDN）" 或
- "...（来源: https://...）"

不使用正式的 APA/MLA/Chicago 格式（除非用户要求）。
```

### 学术格式（用户要求时）

根据用户指定的格式进行，默认非学术。

## 重要规则

### 必须做
- 标注实际查阅过的来源
- 搜索结果引用后标注来源
- 引用不确定时，额外标注"此信息可能有变化"

### 禁止做
- 编造引用 — 绝对不标注没有实际查阅的来源
- 将训练数据中的信息伪装为搜索结果
- 编造 URL 来让回答看起来更可信
