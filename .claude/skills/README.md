# Skills Directory

Reusable workflows for claude-code-haha.

## Available Skills

| Skill | Description |
|-------|-------------|
| [add-model-provider.md](add-model-provider.md) | Add new model providers |
| [run-tests.md](run-tests.md) | Run and write tests |
| [debug-tui.md](debug-tui.md) | Debug terminal UI issues |
| [add-new-skill.md](add-new-skill.md) | Create new skills |

## Usage

Skills in this directory are automatically available when working in the project.

```bash
# Use a skill
/skill-name

# Or reference in conversation
```

## Adding Skills

1. Create a markdown file in this directory
2. Follow the [skill format](../src/skills/bundled/)
3. Keep descriptions concise and actionable
