# PreToolUse Sound Folder

Place `pretooluse.mp3` here.

## Special Sounds

Place special sounds for detected commands:
- `pretooluse-git-committing.mp3` - for `git commit` commands
- `pretooluse-git-pushing.mp3` - for `git push` commands
- `pretooluse-git-pulling.mp3` - for `git pull` commands
- `pretooluse-installing.mp3` - for `npm/pnpm/yarn install` commands
